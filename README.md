# K-means player profiling

This project demonstrates the use of K-means clustering to group soccer players based on physical performance tests.

## What this shows
- Data preprocessing and standardisation
- Unsupervised clustering (K-means)
- Silhouette score for model selection
- PCA used for visualisation only

## Why it matters
In squads with high inter-individual variability, clustering can support more informed training decisions instead of one-size-fits-all approaches.

## Tools
- Python
- pandas, scikit-learn
- Quarto
